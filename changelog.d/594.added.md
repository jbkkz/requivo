- The Claude Code plugin's `/requivo:run` now grounds a **first** session in the repository it runs
  in before asking anything: a bounded look at the manifest, the root README/CLAUDE.md, the top
  level and a narrow search for terms from the request, folded into the same reasoning turn at no
  extra cost. It hands the user a perimeter recap — what the codebase appears to be and what it is
  built with, what already exists that the request touches, the request restated, which context
  cards it is reasoning against (including its own read on whether they fit the domain), and what it
  assumed to get this far — before the single first question (#594).
- Every slot the grounding step fills is graded `inferred`, never `explicit`, and cites the file it
  came from; repository text (a README, a CLAUDE.md, a comment) is treated as untrusted input, the
  same as the client request (#594).
- The CLI gets no scanner of its own in this change — a deliberate scoping decision, not a gap; see
  `decision: plugin-first-repo-grounding` for the graduation trigger (#594).
