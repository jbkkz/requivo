- Discovery no longer ends in a dead end (#784). When a turn asks nothing while readiness still blocks, `requivo answer`, `requivo run` and `discover --once` name the blocking topics and how to settle them (confirm each, or delegate it with "you decide") instead of printing "Discovery converged", and the `requivo status` footer points at `requivo answer` with the same topics. The keyless `/requivo:run` loop does the same: with no question left, it asks the user to confirm or delegate each remaining blocker rather than declaring convergence. The engine's stop rule now matches readiness (a high-impact topic that is assumed, or confirmed but too thin, is still open), and a decision the client delegates is recorded as confirmed with evidence beginning "Client delegated:", so it stops blocking and stays visible as a choice made on their behalf. Readiness itself decides exactly as before; nothing emitted by `--json` moved.
