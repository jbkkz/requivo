- The documents are written in the language you choose (#790). A first `requivo discover` or `requivo run` at a terminal asks which language the documents should be written in, offering the request's language — guessed from its function words, with no provider call; `--docs-language CODE` answers ahead on `discover`, `run` and `session init`, and a run with no terminal takes the request's language, or English when it cannot be told. The choice is recorded as `docs_language` on `session.json` (also in `session show --json`, `status --json` and `session init --json`), and every generator — the brief, the go-to-market plan, the PRD, stories, estimate, criteria, epic and release notes — is told it; ids, slot ids and code-like content stay as they are. The Claude Code plugin's run skill asks the same question at its first checkpoint and passes it to `session init`; every document skill writes in it.
- Compatibility: compatible - one optional field, `null` for every existing session, which reads and generates as English; one additive `--json` key on `status`, `session init` and `session show`; one new flag; a code outside the BCP 47 shape, or longer than 35 characters, is refused as the new `invalid_language` (HTTP 400).
