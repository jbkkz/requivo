- A session that exists but has no model yet (right after `requivo session init`) is refused with a code of its own, `session_has_no_model`, instead of `session_not_found` (#720). It covers `requivo status`, `impact` and `model show` (`--json` envelope, exit code still 1), the HTTP API reads (`/sessions/{slug}/model`, `/status`, `/impact`) and Requivo Web's `GET /sessions/{slug}/export`, which now answer 409 instead of 404, and the MCP tools `get_model`, `get_status` and `get_impact`. A session that does not exist keeps `session_not_found`. In Python, `SessionHasNoModelError` subclasses `SessionNotFoundError`, so an existing `except SessionNotFoundError` still catches it. The `/requivo:run` skill names both codes.
- Compatibility: breaking - a caller that branches on `code == "session_not_found"` or on HTTP 404 to detect a model-less session stops matching it; move it to `session_has_no_model` / 409.
