- The Claude Code plugin installed from the marketplace no longer claims the last release's version while documenting what only `main` has (#769). The marketplace serves `plugins/claude-code` from `main`, so after 3.5.0 a user got a plugin labelled 3.5.0 that documented slot `claims`, which the 3.5.0 CLI refuses, and the preflight's version check saw two equal numbers. Between releases every version site now carries the next patch's `.dev0`, and a test goes red when a `changelog.d/` fragment sits under a release number. The check orders a `.dev` build below the release it becomes and above the one before it, and says that a development plugin beside a released CLI may document a field or flag that CLI rejects, instead of suggesting an upgrade that does not exist yet.
- Compatibility: compatible - `requivo --version`, `doctor`'s `requivo_version` and a new session's `requivo_version` read the next patch's `.dev0` on an install from `main`; a release still carries a plain `X.Y.Z`.
