- A slot keeps the client's own words across turns (#781). When a turn restates a slot with empty evidence, or with evidence that only points back at an earlier turn ("Prior turn.", "as before", "unchanged"), the evidence the slot already had is kept; a slot restated with the same value and confidence keeps it too. A changed value or a confirmation still brings its own evidence. The engine prompt also asks the model to keep prior quotes that still support a value.
