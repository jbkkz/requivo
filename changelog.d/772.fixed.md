- A next step a command prints now repeats `--workspace` when the sessions it read live outside the current directory (#772): the `status` footer, `discover`'s and `answer`'s hints, `session init`'s and `docs`' pointers. The path is single-quoted for a POSIX shell, so a pasted hint runs nothing the path holds, and pasted where it was printed, the command finds the session instead of reporting none. The keyless `/requivo:run`, `/requivo:docs` and `/requivo:status` take `--workspace DIR` in their arguments, never as a session or a document name, and pass it to every command they run, the preflight `doctor` included, which used to describe the current directory's sessions.
