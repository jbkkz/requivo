- An answer turn is told to leave alone the slots the answer does not bear on (#810). The engine prompt and the Claude Code plugin's reasoning guide now say a slot belongs in a refinement only when the answer states, confirms, contradicts or delegates something in it; that a knock-on the engine merely infers is a question, not an edit; that a changed fact (a vendor, a threshold) is replaced where a `value` names it and nothing else moves; and that a restated slot keeps every other sentence and field byte for byte, because a reworded or re-graded slot marks every document built on it stale.
