- When a first `requivo discover`/`run` judges that no installed context card describes the request's domain, the engine now writes the missing card into `REQUIVO_CONTEXT_DIR` (default `~/.config/requivo/context`), shows it in full, and reasons the session against that card alone instead of every unrelated one (#598). The card is filled as typed fields by the existing grounding judgment (no extra call), one line per value and size-capped, refused rather than trimmed; a name an installed card already uses is refused, never overwritten; and a later request in the same domain can select it like any installed card.
