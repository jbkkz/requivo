- One answered fact no longer marks every document stale (#780). A refinement turn now states only the slots it changes, and every slot it leaves out is carried verbatim from the current model instead of being paraphrased, so `changed_slots`, `requivo impact` and the stale list name what actually moved. `requivo model apply` and `model diff` accept such a partial refinement on a session that already has a model, and still accept a complete one; a first model still needs every slot.
- Compatibility: compatible - a partial proposal applied to an existing model used to be refused with `missing_required_slot` and is now completed from that model; a complete proposal still replaces every slot it states (`docs/compatibility.md`, "What a proposal means").
