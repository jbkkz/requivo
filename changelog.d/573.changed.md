- The Claude Code plugin's shared preflight (`REASONING.md`) now offers to install the `requivo` CLI itself, instead of only telling the user what to type. Detection is unchanged — the `requivo doctor --json` probe and its shape-not-wording rule still decide whether the CLI is missing — but a missing CLI now branches into an offer before falling back to the four-things message: it names the exact command before running it, routes by what is actually on the machine (`uv tool install requivo` when `uv` resolves, `pipx install requivo` when only `pipx` does, and never `pip install --user`, which leaves `requivo` off the `PATH`), and asks once. A yes runs that one command, re-probes rather than trusting the installer's exit code, and continues the skill the preflight interrupted so the user does not have to re-issue their request; a no, an install that fails, or a machine with neither `uv` nor `pipx` all fall through to today's four-things message, byte-for-byte unchanged. `README.md`'s Claude Code door drops from six steps to four, all of them typed inside Claude Code — the `uv` prerequisite and its `uv tool install requivo` step leave that door, because the preflight now picks the route; `plugins/claude-code/README.md` describes the same sequence (#573).
